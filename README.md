# WiFi File Transfer 7

Безплатен двупосочен трансфер на файлове между Android и Windows през локална Wi-Fi мрежа или Hotspot.

## Състав
- `Android/` — приложение за Android 10+ (Kotlin), приемащо файлове на порт 8766 и изпращащо към Windows.
- `Windows/` — WinForms приложение за Windows 7 / 10 / 11 (.NET Framework 4.7.2), приемащо файлове на порт 8765 и изпращащо към Android.
- `.github/workflows/` — автоматично изграждане на Windows EXE и Android APK.

## Свързване
1. Свържете телефона и компютъра към една Wi-Fi мрежа или свържете компютъра към Hotspot-а на телефона.
2. Стартирайте приложенията и разрешете достъп през Windows Firewall за частни мрежи.
3. На Android въведете IPv4 адреса на компютъра и изпратете файл.
4. За обратна посока въведете IP адреса на телефона в Windows приложението и изпратете файл.

Портове: Windows приема на TCP 8765; Android приема на TCP 8766.

## Сигурност
Трансферът е предназначен за доверена локална мрежа. Не препращайте портовете към интернет. Потвърждавайте получаването само от познати устройства. Следваща версия ще добави PIN/сдвоение и автоматично откриване.

## Изграждане
Windows: отворете `Windows/WifiFileTransfer7.sln` във Visual Studio 2019/2022 и изградете Release.
Android: отворете папка `Android` в Android Studio; минималната версия е Android 10 (API 29).

Автоматичните файлове се публикуват като GitHub Actions artifacts.
